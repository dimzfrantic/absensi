## Environment
Windows 10/11

**[XAMPP / PHP Version 8.2.12](https://sourceforge.net/projects/xampp/files/XAMPP%20Windows/8.2.12/xampp-windows-x64-8.2.12-0-VS16-installer.exe)**

Laravel Framework 12.16.0


## Installation
1. environment PATH edit, ganti lokasi xampp/php
2. edit php.ini (aktif zip, aktif gd)
3. composer install
4. copy dan rename .env
5. php artisan key:generate
6. buat database
7. php artisan migrate
8. php artisan db:seed
9. npm install
10. npm run dev
11. php artisan storage:link
